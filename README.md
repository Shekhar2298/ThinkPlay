ThinkPlay - Real-Time Quiz Platform

ThinkPlay is a real-time quiz platform currently under development. It provides quiz functionality with user authentication, real-time communication, and cloud-based services.

Features
Real-time quizzes using WebSockets
REST APIs
User authentication and authorization
Role-based access control
PostgreSQL database
Kafka-based event processing
Database indexing and query optimization
Android application using Flutter and Dart
AWS-based deployment
